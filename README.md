## 💍 О бренде

IULIYA M.A.R.O. — ювелирная мастерская ручной работы: украшения
производятся штучно, каждое — с историей и индивидуальным дизайном.
Перед проектом стояла задача: без IT-команды выстроить цифровую экосистему,
которая держит стандарт бренда на уровне продукта.


## 🧩 Что сделано

| Продукт | Что решает | Для кого |
|---|---|---|
| **Бренд-сайт** | Узнаваемость, философия и эстетика бренда | клиенты |
| **Трекер «мастер–клиент»** | Прозрачное ведение заказа от заявки до доставки | мастер, помощник, клиент |
| **Внутренняя аналитика** | Выручка и статистика по заказам и клиентам | мастер |

Флагман экосистемы — **трекер заказов**: мастер видит заявки, меняет статусы,
пишет комментарии; клиент по персональной ссылке без регистрации следит
за прогрессом заказа. Весь процесс сопровождается уведомлениями в Telegram.


## 🚀 Трекер «мастер–клиент»

**Три роли:**
- **Мастер** — полный доступ: заказы, комментарии, статистика, удаление.
- **Помощник** — управление заказами без статистики и удаления.
- **Клиент** — отслеживание своего заказа по персональной ссылке.

**Жизненный цикл заказа:**
`Новая заявка → Бронь → Оплата получена → В работе → Отправлено → Доставлено`

**Что умеет:**
- Карточка заказа: все поля, фото украшения, трек-номер, комментарии, история статусов.
- Фильтры по статусу и поиск по заказам.
- Клиентская страница: прогресс-бар, статус с датой, фото, ссылка на отзыв.
  Без сумм и внутренних комментариев.
- **Telegram-уведомления**: новые заявки и оплаты — мастеру; «в работе» и отправка — клиенту;
  напоминания, если заказ застрял (7 дней) или не получен отзыв (3 дня).
- Адаптивный интерфейс по брендбуку: Playfair Display + Inter, шампань `#FBDDB1` на изумруде `#073D37`.

> **[Попробовать демо](DEMO_URL)** — демо-доступ: мастер `master` / `maro-master`.

## 🗂 Как это устроено

```
app/
  main.py              # FastAPI-приложение
  config.py            # настройки из переменных окружения
  models.py            # Order, StatusChange, OrderComment
  routers/             # admin (админка), client (отслеживание), auth

  templates/           # HTML-шаблоны по брендбуку
  static/              # стили, шрифты, логотип, фавиконка
```
